# Marginalis

[English](README.en.md)

Marginalis сделан по почерку Александра Осадчука, отца Дмитрия Осадчука.

**Презентация:** [marginalis.art](https://marginalis.art)

## Начертания

| Начертание | Насыщенность | Файлы |
|---|---|---|
| Regular | 400 | `Marginalis-Regular` |
| Bold | 700 | `Marginalis-Bold` |
| Rounded | 400 | `Marginalis-Rounded` |
| Rounded Bold | 700 | `Marginalis-RoundedBold` |

Все четыре начертания входят в одно семейство Marginalis.

## Набор знаков

- Кириллица (русский алфавит) и латиница, только прописные. Строчные при наборе выводятся прописными.
- Цифры, пунктуация, кавычки «» „“ “” ‘’, математические знаки, @ & © № и полный набор с клавиатуры.

## Скачать

- `fonts/otf` — для установки в систему.
- `fonts/ttf` — для системы и приложений.
- `fonts/woff2` — для сайтов.

```css
@font-face { font-family: "Marginalis"; src: url("Marginalis-Regular.woff2") format("woff2"); font-weight: 400; font-display: swap; }
@font-face { font-family: "Marginalis"; src: url("Marginalis-Bold.woff2") format("woff2"); font-weight: 700; font-display: swap; }
@font-face { font-family: "Marginalis Rounded"; src: url("Marginalis-Rounded.woff2") format("woff2"); font-weight: 400; font-display: swap; }
@font-face { font-family: "Marginalis Rounded"; src: url("Marginalis-RoundedBold.woff2") format("woff2"); font-weight: 700; font-display: swap; }
```
